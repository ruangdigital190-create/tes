Informasi pelanggan

Pertanyaan umum

Apakah pembayaran QRIS otomatis tersedia?

Belum. Website ini mengarahkan konfirmasi pembayaran kepada admin. Integrasi gateway dan webhook diperlukan sebelum pembayaran QRIS otomatis bisa dinyatakan aktif.

Apakah admin dapat melihat data pendaftar?

Ya. Dashboard admin menampilkan akun terdaftar sesuai izin Row Level Security dari Supabase.

Apakah stok dan harga dapat berubah?

Ya. Admin dapat memperbarui harga, stok, catatan, gambar, dan paket; perubahan akan tersinkron ke pelanggan.

Apa yang harus dilakukan jika salah mengisi Player ID?

Periksa Player ID sebelum checkout dan hubungi admin secepatnya. Perbaikan bergantung pada status pesanan.
